# dill
A modular script suite for managing system updates on Arch Linux-based distributions. This tool automates the update process, includes mirror rating, package querying, and separate handling for pacman and AUR updates.
This tool is designed as yet another AUR handler for Arch Linux.

## Dill ##
- dill is the replacment to Pickles Update
